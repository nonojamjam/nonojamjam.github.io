Verify, remember, compute less — 7-DOF Franka Panda

A 7-joint arm with the published kinematics of the Franka Emika Panda (simplified geometry) reaches clustered targets in 3D. Each move is proposed by a planner, checked by a forward-kinematics gate before execution, and remembered if it passed; similar situations replay the remembered move instead of calling the planner. What this is and is not. Kinematics follow Franka's published Denavit-Hartenberg parameters and Panda joint limits; links are drawn as cylinders, not the real meshes, and there is no dynamics or collision geometry. The planner is a damped-least-squares step toward the target with injected mistakes (30, 50 or 70% wrong) — a stand-in, not an LLM. No LLM run was made on this arm; the pre-registered LLM results (2-link 60 → 24 calls, 3-joint 33 → 12, both 30/30) are on the study page. With seven joints a fingertip position cannot be turned back into one joint reading, so here the sensor is used directly: the error to the target and the gate's prediction start from the measured fingertip.
