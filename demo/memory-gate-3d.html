Verify, remember, compute less — 3D arm

A 3-joint arm (base yaw, shoulder, elbow) reaches clustered targets in 3D. Each move is proposed by a planner, checked by a forward-kinematics gate before execution, and remembered if it passed; similar situations replay the remembered move instead of calling the planner. What this is and is not. The planner here is a small analytic stand-in with injected mistakes (a wrong move 30, 50 or 70% of the time — the memory saves more when the planner is less reliable), not an LLM, so the numbers on this page are illustrative. The pre-registered 3D run with a real LLM planner (GPT-6.1 Pro) went from 33 to 12 planner calls at 30/30 success; it and its raw data are on the main page. The arm, gate, memory key and replay rule follow that run's definitions, with two differences made for clarity: after four rejected proposals the arm holds still, and with the gate off the memory stores moves without checking them.
