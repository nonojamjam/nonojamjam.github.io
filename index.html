B.S. Electronic Engineering, Chungbuk National University (Feb 2027) · Physical AI

I study when a robot can trust what its AI perceives and plans — and how much it should re-check. At KAERI I built a forward-kinematics gate for VLM robot commands and an LLM wiki the agent writes and reads as its own memory. I am now testing how verified experience can cut computation, and what happens when the robot's own state estimate is wrong.

  • verify before acting (runtime assurance)
  • memory of verified experience
  • small models first, large ones only when needed

Preliminary study 예비 연구

Memory and verification on a Panda, without an oracle

2026.10 · self-initiated · MuJoCo Panda · local LLMs (4B and 32B) · pre-registered, held-out scenes · two steps

The robot sees only through a camera image, a range tracker, an IMU and touch; a small LLM plans, a check decides, and verified steps become memory.

  • 793 → 0 large-model calls at the same 36/36: a 4B planner with a 32B model's verified memory
  • 0 → 108/108 with a shoulder reading 0.15 rad off: independent sensors, then observe → verify → act
  • −78 to −96 % large-model calls on a harder level (a wall, a box to stack on), reusing that memory, every box placed

Next study: a harder task where the fault starts halfway through — already playable in the live demo.
