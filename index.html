FedV9 — Noise-Robust Object Detection via Heterogeneous Relational KD

2025.11 – present · team lead

Keeping a lightweight detector accurate under satellite sensor noise by distilling a foundation model's relational structure.

  • Distill DINOv2 (ViT) → YOLOv8s-seg (CNN) across a heterogeneous gap via distance-wise relational KD + 50:50 mixed-noise training.
  • Built the full ML pipeline solo: RKD loss, custom Ultralytics trainer (SPPF hook + adapter + mixed noise), and 3 framework-level bug fixes.
  • Teacher & adapter detached at inference → zero added cost.

Result (σ=0.3, iSAID): noisy mAP50 0.009 → 0.196, clean 0.278 → 0.426; deployed model 11.8M / 22MB.

Imagination Learning — Finding & Verifying Where LLM/VLM Robot Control Breaks (KAERI)

2026 · ~6 mo intern

Pinpointing the failure modes of zero/few-shot LLM-VLM control — and building ways to check for them.

  • Designed controlled ablations (DOF 1→2→5; hints No-hint / CoT / joint-info / image feedback; VLM read-vs-generate) to isolate where spatial reasoning fails.
  • Surfaced concrete failure signals: joint-info hints hurt (165.7mm → 276.9mm), a Verifier ceiling at 5-DOF, and same-family self-verification bias.
  • Ran the full research loop solo — experiment design, data collection, visualization, and the report submitted to the lab.

What it establishes: a model checking itself is not enough. Oral presentation + proceedings, Korea Society of Industrial Information Systems 2026. The project closed in 2026; that negative result is what moved me toward independent, physically-grounded checks.

eLoran Coherent Accumulation under Sample Loss (NAVIS Lab)

2025.12 – present

Recovering time-of-arrival estimation when random samples are dropped at the receiver.

  • BPF + valid-sample filtering, recursive noise suppression, reference-based interpolation + cross-correlation, S-Transform/FFT smart filtering.
  • Hybrid hard/soft-decision sub-sample PPM demodulation.
  • Evaluated every variant against a 1000-run Monte-Carlo baseline rather than a single trial — which is what showed the compensation schemes were overfitting.

Results: ~7 dB output gain at SNR −20 dB · PPM BER ×1.67 better · 5→3 accumulations → 1.5 dB SNR.
